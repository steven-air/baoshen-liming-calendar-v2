# 保身立命 · 戒期日历

独立于旧版 `baoshen-liming-calendar` 的全新前端实现。项目沿用旧站的历法计算引擎，重新设计为适合桌面浏览、移动端查看和高清打印的中式宣纸历书。

## 功能

- 复用原站 1901—2099 农历、干支、节气与戒期数据逻辑
- 七列周一至周日月历，支持真实月份天数、闰年和前后月补位
- 日期格显示公历、农历、日柱、具体戒期名称与节气
- 大忌、戒期、斋戒月、节气、普通日使用对应颜色、圆形标记和文字标签
- 普通日使用浅绿色整格，并显示“本日为毫无忌犯之日 ✓ / 宜保精养神 · 清心寡欲”
- 月份切换、回到今天、日期详情抽屉和本月事项摘要
- A4 打印样式与移动端响应式布局

## 本地预览

```powershell
python -m http.server 4175
```
